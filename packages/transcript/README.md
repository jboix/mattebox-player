A transcript for the
[Mattebox player](https://github.com/jboix/mattebox-player): the subtitles
of a programme as a list of lines, with a search, in a panel over the
player.

- Importing the package registers `<mbx-transcript>` and `<mbx-transcript-button>`.
- The package imports the engine's `mattebox/stages/transcript` stage.

```sh
npm install @mattebox/player-transcript @mattebox/player mattebox
```

The [guide](https://github.com/jboix/mattebox-player/blob/main/docs/guide/README.md)
documents the transcript.
